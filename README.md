# ASTART Website

This folder is ready to publish with GitHub Pages.

## Publish
1. Create a new public GitHub repository named `ASTART`.
2. Upload **the contents of this folder** to the repository root. Do not upload the containing folder itself.
3. Commit the files.
4. Open **Settings -> Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. GitHub will provide a public website URL after deployment.

The homepage file is `index.html` and the site artwork is in `assets/`.
